# Historical records

This directory preserves dated design decisions and implementation plans created
while developing Tagsmith. It is intentionally separate from the current
product, contribution, and workflow documentation.

- [Design records](designs/) explain the decisions made for a feature.
- [Implementation plans](plans/) capture the original execution approach.

These documents are snapshots. Their stated status, task checkboxes, file
paths, and version references may describe the repository at the time they
were written; use the current code and primary documentation as the source of
truth.
